# 公开版本变更说明

- 原工程保持原样，并在仓库目录外生成完整本地备份及逐文件 SHA-256 清单。
- 删除三个默认页眉中的单位图片节点，移除标志图片文件。
- 删除标题栏的默认单位名称，同时修改自动新增页面的模板。
- Word 导出页眉使用通用文字和版本号，不保留标志图或单位栏。
- 页脚地址、电话、传真替换成技术支持占位文字。
- 默认型号改为 `PRODUCT-001`，产品规格与版本改为通用占位内容。
- 清除示例配置中的原内网模型地址、默认模型、密钥值和本机曲线目录。
- 根目录不复制实际 `.env`；提供可复制的 `.env.example`。
- 修复空模型地址阻止后端启动的问题；不配置助手也能使用其他功能。
- 版图测试改用合成数据，避免依赖本地生成的实际产品报告。
- 不收录实际版图产物、第三方离线安装缓存、预装依赖和历史 vendor；依赖通过清单安装。
- L-Edit 提供官方产品链接和本机配置脚本，软件本体由使用者自行获取与授权。
- 公开版提供 README、GitHub 操作教程和第三方依赖声明，不擅自新增项目开源许可证。

页面编辑、Excel 参数导入、曲线、图片和矢量图编辑、HTML/PDF/Word 导出仍使用现有实现。模型助手和真实 TDB 生成依赖使用者自行配置的服务与 L-Edit；这两项外部服务需要在目标部署环境中验收。
